TENTANG KEUANGAN

Mengenal Website Penghitung Biaya Kuliah

Website KEUANGAN merupakan sebuah program berbasis web yang dibuat untuk membantu mahasiswa menghitung estimasi biaya perkuliahan. Melalui website ini, pengguna dapat memasukkan biaya kuliah dasar, jumlah SKS, tarif per SKS, dan biaya tambahan.

Hasil perhitungan ditampilkan secara otomatis sehingga lebih mudah dibaca dan dapat dicetak sebagai laporan.

FITUR WEBSITE

Fitur Utama Website KEUANGAN

Website KEUANGAN menyediakan beberapa fitur untuk membantu mahasiswa memperkirakan biaya kuliah.

01

Identitas Mahasiswa

Memasukkan nama, NIM, dan program studi.

02

Perhitungan Biaya

Menghitung biaya kuliah dasar dan biaya SKS.

03

Hasil Otomatis

Menampilkan total pembayaran secara otomatis.

04

Cetak Laporan

Mencetak rincian pembayaran dengan mudah.
